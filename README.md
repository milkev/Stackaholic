### Stackaholic
If an items stackable, now it stacks to 64. No ifs ands or buts, if it stacks, now it stacks to 64.

### Stackaholic and Neoforge!
Playing on Neoforge but want to use Stackaholic? Look no further than [Sinytra](https://www.curseforge.com/minecraft/mc-mods/sinytra-connector)! Stackaholic has full compatability with Sinytra for playing on Neoforge.
